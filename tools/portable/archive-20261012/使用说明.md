# llm-wiki 便携版 · 全量导入包（2026-10-12）

> 自带 Python 运行时和 7z 解压器，**目标电脑什么都不用装**。
> 版本：放量版 exe（SHA256 `54c39c9d408673227479f1c4ce615b3873aa454c9dacd20e8cbdd06bd0728eac`，
> 含 F1-F8 审查整改、H2/L6 拆题通道、思考关闭档位、MinerU 三级降级）。

## 使用（就三步）

1. **解压**：在目标电脑上，双击 `7z\7z.exe` 旁边的压缩包没法直接图形界面解压的话，
   用这个命令（或电脑上装过的任何解压工具）：
   ```bat
   7z\7z.exe x llm-wiki-portable.7z -oD:\
   ```
   解压后得到 `D:\llm-wiki-portable\` 文件夹。
2. **退出旧版**：如果这台电脑上开着旧版 LLM Wiki（右下角托盘图标），右键退出它。
3. **双击 `一键全量导入.bat`**：黑窗口会显示四个步骤（部署设置 → 注入 1,746 个任务
   → 启动应用 → 等待就绪），看到 **「全量导入已开始」** 就成功了，窗口可以关掉。
   应用窗口会自动弹出，导入在后台进行，**关机前让它跑完或保持开机**。

就这些。跑的过程中随时双击 **`查看进度.bat`** 看进度（任务计数、question/section 页数）。

## 包内容

| 路径 | 内容 |
|---|---|
| `一键全量导入.bat` / `查看进度.bat` / `还原本机设置.bat` | 双击入口（内置 Python，免安装） |
| `runtime\` | Python 3.12.10 嵌入式运行时（官方 embeddable 包） |
| `llm-wiki.exe` + `mcp-server\` + `pdfium\` | 应用本体（相对 exe 解析，免安装） |
| `data\app-state.json` | 全部设置与 API key（方舟/智谱/embedding/MinerU token）——**含明文密钥，勿外传** |
| `data\wiki\` | 案例库完整副本 24G：19,080 个 md、1,746 份 PDF、1,746 份 MinerU 缓存、向量库 |
| `data\知识库\` | 准则库 843M（设置里注册的第二个项目） |
| `bin\run-full-import.py` | 一键脚本本体（bat 调用它；想看预览可手动跑无参数 = dry-run） |

## 进度怎么读（`查看进度.bat` 输出）

- `pending=N`：排队中；`done` 的自动出队消失；`failed=N`：失败数
- `question 页: N`：预期最终冲向 ~7,700+；`section 页` 数千
- 全部 1,746 份都有 MinerU 缓存，不依赖这台电脑的解析能力；L6 难例兜底走云端 key（已内置）

## 中途失败了怎么办

- 有一批 `failed`：再双击一次 `一键全量导入.bat`（幂等：已 done 的不重跑，failed 自动复位重试）
- 想把这台电脑的 LLM Wiki 设置还原回原样：先退出 LLM Wiki，双击 `还原本机设置.bat`

## 跑完之后（拿回开发机）

1. 退出应用，把整个 `data\wiki\` 拷回开发机；
2. 替换 `C:\library\wiki` 前先打 tar 快照（惯例 `.data/wiki-cases-*.tar.gz`）；
3. 替换后做应用侧验证：`/graph` 节点对账、`/search` 抽查可检索。

## 技术备注

- `--apply` 会把便携设置写入 `%APPDATA%\com.llmwiki.app\`（原设置自动备份到 `bin\app-state-backups\`）；
- 任务注入在应用未启动时完成（应用内存态会覆盖手改——脚本已按正确顺序内置）；
- 脚本与 bat 全部动态定位自身路径，解压到任意盘符任意目录均可；
- `C:\library\监管问答` 未包含（未在项目注册表里，与本次重放无关）。
